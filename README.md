# راوی — دستیار هوشمند ثبت گزارش (سازمان رزم سوم فراجا)

سامانه بازنویسی‌شده به زبان React و TypeScript همراه با موتور هوش مصنوعی پیشرفته Gemini 3.8 Flash برای دریافت، دسته‌بندی و پردازش گزارش‌های انتظامی و شهروندی.

## ویژگی‌های اصلی
- **رابط کاربری بومی فارسی و هماهنگ با هویت بصری سازمان رزم سوم فراجا**: راست‌چین کامل (RTL)، تایپوگرافی وزیر (Vazir)، پالت رنگی سبز انتظامی.
- **موتور هوش مصنوعی ارتقایافته (Gemini 3.8 Flash)**:
  - تحلیل دقیق متون گزارش‌ها و استخراج خودکار فاعل، زمان، مکان، وسایل نقلیه، اقلام و ادله مستند.
  - طبقه‌بندی هوشمند در بیش از ۷۰ موضوع انتظامی و شهروندی.
  - تعیین حوزه خبری پیشنهادی (انتظامی، قضایی، حوادث، پلیس فتا و...) و درجه‌بندی کیفی گزارش.
  - هدایت گام‌به‌گام مصاحبه برای گزارش‌دهندگان ناآگاه با ارائه گزینه‌های پیشنهادی تک‌ضربه.
  - تبدیل صوت فارسی به متن با Gemini Transcribe.
- **غربالگری و اولویت‌سنجی حوادث فوری (Triage)**:
  - تشخیص سریع وضعیت‌های اضطراری جانی، نزاع مسلحانه، آتش‌سوزی و حوادث با امکان شماره‌گیری مستقیم ۱۱۰، ۱۱۵، ۱۲۵ و ۱۲۳.
- **ویرایشگر استاندارد پلاک ملی ایران**:
  - پشتیبانی از پلاک‌های ملی، تاکسی، دولتی، انتظامی، موتورسیکلت، مناطق آزاد و گذر موقت.
- **فرم چندمرحله‌ای استاندارد (Stepper)**:
  - مرحله ۱: شرح موقعیت / ضبط یا پیوست صوت / مصاحبه هوشمند.
  - مرحله ۲: بازبینی استخراج‌های هوش مصنوعی و سؤالات تکمیلی.
  - مرحله ۳: پیوست مستندات (تصویر، ویدئو، صوت، سند PDF تا ۱۰ فایل / ۱۰۰ مگابایت).
  - مرحله ۴: بررسی نهایی، احراز اطلاعات اظهاری گزارش‌دهنده (نام، استان، شماره ۱۰ رقمی، رده و سمت) و صدور شناسه رهگیری (RV-XXXXXX).
- **کارتابل گزارش‌های من**:
  - جست‌وجو، مشاهده جزئیات و دانلود متن رسمی گزارش در قالب استاندارد فراجا.

## اجرا و راه‌اندازی
```bash
npm install
npm run dev
```
سامانه بر روی پورت ۳۰۰۰ اجرا می‌شود.
